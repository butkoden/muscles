# Muscles naming

## English

`Muscles` is the public name of the framework.

Use these names consistently in documentation, examples, metadata and public
developer-facing text:

- `Muscles` - framework and brand name.
- `muscles` - Python package and import name.
- `muscles-*` - official package and repository identifiers in the Muscles ecosystem.
- `Muscles application` - an application built on Muscles.
- `Muscles ASGI`, `Muscles WSGI`, `Muscles CLI` - human-facing names for adapters and tools.

Do not introduce adjective-based legacy variants or alternative lowercase
repository prefixes as public names. Existing technical identifiers stay
lowercase unless a separate breaking-change task explicitly changes them.

## Русский

`Muscles` - публичное название фреймворка.

Используйте эти названия единообразно в документации, примерах, metadata и
публичных developer-facing текстах:

- `Muscles` - название фреймворка и бренда.
- `muscles` - название Python package и import path.
- `muscles-*` - официальные package и repository identifiers экосистемы Muscles.
- `Muscles application` - приложение, построенное на Muscles.
- `Muscles ASGI`, `Muscles WSGI`, `Muscles CLI` - human-facing названия адаптеров и инструментов.

Не вводите legacy-варианты на основе прилагательных или альтернативные
lowercase-префиксы репозиториев как публичные названия. Существующие
технические identifiers остаются lowercase, пока отдельная breaking-change
задача явно не изменит это правило.
