# Muscles naming

`Muscles` is the public name of the framework.

Use these names consistently in documentation, examples, metadata and public
developer-facing text:

- `Muscles` - framework and brand name.
- `muscles` - Python package and import name.
- `muscles-*` - official package and repository identifiers in the Muscles ecosystem.
- `Muscles application` - an application built on Muscles.
- `Muscles ASGI`, `Muscles WSGI`, `Muscles CLI` - human-facing names for adapters and tools.

Do not introduce adjective-based legacy variants or alternative lowercase
repository prefixes as public names. Existing technical identifiers stay
lowercase unless a separate breaking-change task explicitly changes them.
